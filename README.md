# Data-Driven Login Test Suite (Selenium + Pytest)

Automated login tests using Selenium WebDriver and Pytest, testing multiple username/password combinations in a single parametrized test function.

## What this tests
- Valid login succeeds
- Wrong password shows error
- Locked-out user shows error
- Empty username/password shows error

## Tech stack
- Python
- Selenium WebDriver
- Pytest (with parametrize for data-driven testing)
